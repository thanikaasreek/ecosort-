



# EcoSort: AI-Powered Waste Classification System

An intelligent waste management and classification web application built using Python (Flask) and a custom-trained TensorFlow/Keras MobileNetV2 deep learning model to promote proper recycling habits.

## 🚀 Features
* **AI-Powered Image Classification:** Accurately classifies waste items into appropriate categories using a fine-tuned MobileNetV2 architecture.
* **Interactive Web Interface:** Clean HTML/CSS/JS frontend allowing users to interact with the backend seamlessly.
* **REST API Backend:** Powered by Python and Flask to process image inputs and return real-time classification results.

## 🛠️ Tech Stack
* **Backend:** Python, Flask, TensorFlow, Keras
* **AI Model:** MobileNetV2 (Transfer Learning)
* **Frontend:** HTML, CSS, JavaScript

## 📁 Project Structure
* `server.py` - Flask backend server application
* `index.html` - Frontend user interface
* `waste_mobilenet.keras` - Trained TensorFlow/Keras classification model
* `class_names.json` - Mapping of model output indices to class labels
* `requirements.txt` - Python package dependencies

## ⚙️ Setup and Installation
1. **Clone the repository:**
   `git clone https://github.com/thanikaasreek/ecosort-.git`
2. **Install dependencies:**
   `pip install -r requirements.txt`
3. **Run the application:**
   `python server.py`
